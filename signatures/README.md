# 小唐话词库

这里是肥鱼那句「个性签名」的**外部词库** —— 句子不写在代码里，改这里就行。

## 怎么加一句

1. 打开任意一个 `.txt`（或新建一个，**后缀是 `.txt` 即可**；文件名建议用英文/数字）
2. **一行写一句**，写完保存
3. 不用重启 —— 程序每次取签名时会检查文件有没有变，变了就自动重载

```text
# 以 # 开头的是注释，不会显示
# 空行会被忽略
这一行才是真正的签名
```

## 出现在哪

| 位置 | 时机 |
|---|---|
| 对话窗口右下角 | 每收到一条肥鱼回复就换一句 |
| 控制台启动横幅下方 | 每次启动随机一句 |
| 控制台退出时 | 告别语后 |

## 现有文件

| 文件 | 内容 |
|---|---|
| `01_classic.txt` | 经典：咸鱼自嘲 / 文艺 / 打工人 |
| `02_fish.txt` | 鱼味特调：水里、潮汐、钓竿、清蒸红烧 |
| `03_tech.txt` | 技术味特调：注释、调试、删库、优雅 |
| `04_real_logs.txt` | 唐事录：真实翻车实录（都有日志出处）|

> 📌 文件名一律用**英文**（安装器解包链路对非 ASCII 文件名敏感）；
> **内容**随便写中文，不影响。

> 想清空某一类，把那个文件里的行删掉即可；**整个目录删掉也不会报错**（只是不再显示签名）。
