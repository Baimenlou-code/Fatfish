# 🐟 肥鱼 FatFish 启动器 · v2.0.1

> 这是一个装在你自己电脑上的 AI 助手窗口。它不只会聊天 —— 它能读你的文件、改你的文件、跑命令、搜网页、画图，**而且只在你能指定的那个文件夹里动手**。
>
> 这份说明只讲怎么用。照着从上往下做，一次就能跑起来。
>
> 🧩 **可选插件**（视觉理解 / 文生图 / 以图生图）在另一个仓库：**[FatFish-Plugins](https://github.com/Baimenlou-code/FatFish-Plugins)** —— 装法见第五节。

---

## 一、三分钟装好

### 第 1 步：确认你是 Windows 10 或 11（64 位）

不是这两个系统的，这个版本跑不了。

### 第 2 步：装依赖（只做一次）

程序本体只有 1 MB 出头，真跑起来要靠一个微软的运行时（.NET 10 桌面运行时）。它被单独放在**依赖包**里 —— 不装它，程序打不开。

**拿到的是安装包**：先运行 `FatFish-2.0.1-Deps-dotnet10` 里的 `install-deps.cmd`（要联网，约 55 MB；已经装过的机器会直接告诉你「不用再装」），再运行主安装包的 `install.cmd`。

**拿到的是源码文件夹**：打开程序文件夹，进 `.setup`，**双击 `install.cmd`**。

- 会弹一个黑窗口自己下载、自己装，等 1～3 分钟；
- **不需要管理员权限**，不会改系统里的东西；
- 窗口最后会把版本号打出来（`10.0.403` 之类的），看到它就成功了；
- 之后不想要了，删掉 `%LOCALAPPDATA%\Microsoft\dotnet` 这一个文件夹就干净了。

> 如果你这台电脑已经装过 .NET 10 SDK，这步可以跳过。

### 第 3 步：填一串钥匙（只有一个文件要改）

1. 打开程序文件夹；
2. 新建一个**文本文件**，名字叫 `.env`（**前面有个点，后面没有 `.txt`**）；
3. 用记事本打开它，写一行：

```
FATFISH_API_KEY=sk-你的密钥
```

4. 保存，关掉。

密钥在模型服务商（默认 DeepSeek）的官网后台里拿，形如 `sk-` 开头的一长串。

> ⚠️ 最常见的一个坑：记事本会偷偷把文件存成 `.env.txt`，程序就找不到它。
> 保存时把「保存类型」选成「所有文件」，或者存完在资源管理器里确认一眼文件名。

### 第 4 步：双击打开

- **拿到了打包好的程序**：双击 `FatFish.exe`；
- **拿到的是源码文件夹**：双击 `run.cmd`（第一次要编译，慢一点，之后快）。

### 第 5 步：怎么知道一切正常

看窗口**右上角那个小圆灯**：

| 灯 | 意思 | 怎么办 |
|---|---|---|
| 🟢 绿 | 好了，可以开始用 | 直接说话 |
| 🔴 红 | 缺密钥，或者 `.env` 没读到 | 看底部「日志」页，第一段就会写清楚缺什么 |
| ⚪ 灰 | 还没启动完 | 等两秒 |

灯右边会显示当前用的模型名（默认 `deepseek-flash`）。

## 二、界面长什么样

窗口分成五块，从上看下去认一遍就够了：

```
┌──────────────────────────────────────────────────────────┐
│ 文件  编辑  视图  帮助                                     │  ← 菜单栏
├──────────────────────────────────────────────────────────┤
│ ➕ 🗑 📁 ⚙ ✖ ☰ 📄  [插件] [🔒审批]              🌙     │  ← 工具栏
├────────────┬─────────────────────────────────────────────┤
│            │                                             │
│  工作台     │              对话区                         │
│  文件树     │      （左边那条竖色条表示是谁在说话）        │
│            │                                             │
├────────────┴─────────────────────────────────────────────┤
│  [日志]  [工具调用]                                       │  ← 底部面板
├──────────────────────────────────────────────────────────┤
│ 状态提示 │ 工作台目录 │ 用量 │ 余额 │ 工具 12 个 调用 3 次│  ← 状态栏
└──────────────────────────────────────────────────────────┘
```

### 工具栏上的按钮（从左到右）

| 按钮 | 颜色 | 点了会怎样 |
|---|---|---|
| **＋** | 绿 | 新建会话：清掉当前对话、断开记忆，重开一段（`Ctrl+N`） |
| **删除图标** | 红 | 和上面一样，清空对话与用量统计。**不会删磁盘上的历史记录** |
| **文件夹** | 黄 | 用资源管理器打开「工作台目录」 |
| **齿轮** | 灰 | 打开配置编辑器（改 `.env`，见第四节） |
| **✖** | 红 | 停止这次回复（等于按 `Esc`），已经打出来的字留着 |
| **列表** | 蓝 | 显示 / 隐藏左边的文件树 |
| **文档** | 蓝 | 显示 / 隐藏底部的日志面板 |
| **插件** | — | 列出所有插件，点一行就是启动 / 停止（见第五节） |
| **锁** | 四色 | 审批档位。**颜色就是当前有多严**，点开可换档（见第三节） |
| **月亮 / 太阳** | — | 白天 / 夜间配色，当场切换，不用重启 |

### 左栏：工作台文件树

这里列出来的，就是**程序能看、能改的全部范围**。单击选中，双击用系统默认程序打开文件。

隐藏了一些会刷屏的目录（`bin`、`obj`、`node_modules`、`venv`、`.git` 等），属于正常现象。

### 底部两页

| 页签 | 写什么 |
|---|---|
| **日志** | 程序自己的运行记录：启动自检、配置载入、联网结果、报错堆栈。**出问题先看这一页** |
| **工具调用** | 模型每一次动手的流水：时间 / 工具名 / 成功还是失败 / 参数 / 耗时 |

### 对话区的颜色条

蓝 = 你说的 · 橄榄绿 = 肥鱼说的 · 灰 = 系统提示（核验结论、报错之类）。

## 三、每天怎么用

### 1. 说话就行

在下方输入框打字，**按 Enter 发送**。

| 想干什么 | 按键 |
|---|---|
| 发送 | `Enter` |
| 换行（写多行） | `Shift + Enter` |
| 停下它正在写的回复 | `Esc` |

输入框会跟着内容自动变高，长到一定程度出现滚动条。

### 2. 它会自己动手

你让它做事，它真的会做：读文件、改文件、跑命令、搜网页、画图、开后台任务。
所有这些动作都被**锁在工作台目录里** —— 想动这个目录以外的东西，会被直接拒绝。这是刻意的。

### 3. 遇到危险动作，它会先问你

改文件、删文件、跑命令这类有副作用的动作，可能弹出一个**审批窗**，问你要不要放行。你点允许或拒绝。

顶栏那个**锁**图标就是审批档位，四档，颜色越往后越松：

| 颜色 | 档位 | 会怎样 |
|---|---|---|
| 🔴 红 | 最严 | 什么都要问 |
| 🟡 黄 | 读免批 | 读文件、列目录自动放行；写 / 删 / 跑命令仍然问你 |
| 🔵 蓝 | **除敏感外免批（默认）** | 写、删、跑命令、后台任务都自动放行；只有碰到敏感文件才问你 |
| 🟣 紫 | 凭密码 | 交付给别人用时用这档 |

觉得被问烦了就点它换档；想严格一点也点它。

### 4. 第二道闸：双人核验

菜单 **编辑 → 双人核验**，三档：

| 档 | 含义 |
|---|---|
| **AUTO**（默认） | 只有有副作用的动作才送另一个模型复核，省 token |
| **ALL** | 连读文件也复核，最严，但每轮多花一次钱 |
| **OFF** | 关掉复核。**人工审批那道闸还在**，只是没有第二个 AI 替你挑错 |

### 5. 开新会话 / 清空

点绿色 **＋** 或按 `Ctrl+N`。对话界面和模型记忆都清空，**磁盘上的历史记录不会被删**。

### 6. 想夜里用

点工具栏最右边的月亮，或菜单 **视图 → 夜间模式**。当场切换，正在写的回复不会被打断。

想每次都用夜间，就在 `.env` 里加一行 `UI_THEME=dark`。

### 7. 想知道「现在到底跑的是哪个模型、哪个目录」

菜单 **帮助 → 关于肥鱼**：版本、内核状态、模型名、工作台路径、账户余额全在里面。

菜单 **帮助 → 快捷键**：把所有键位和鼠标操作列一遍。

## 四、改配置（别用记事本）

菜单 **文件 → 编辑配置文件 .env**，或者点工具栏那个灰色齿轮。

打开的是一张**表单**，不是文本文件：

1. 按用途分好了组（模型 / 联网 / 核验 / 界面 …），每一项底下有一句人话说明；
2. 高级项默认折叠着，点开才看得见；
3. 改完看窗口**底部的体检结果** —— 常见错误会当场标出来（比如地址少了 `https://`、温度写成 20、同一个键填了两遍）；
4. 点 **保存**（自动备份原文件），或者点 **保存并重启**（一步到位）。

**改错了怎么办**：配置旁边会留一份带时间戳的备份（`.env.日期_时间.bak`），把它的名字改回 `.env` 就回去了。

### 最常改的几项

| 键 | 管什么 | 例子 |
|---|---|---|
| `FATFISH_API_KEY` | 密钥，不填什么都干不了 | `sk-xxxx` |
| `FATFISH_MODEL` | 用哪个模型 | `deepseek-flash` |
| `FATFISH_BASE_URL` | 接口地址（换服务商时改） | `https://api.deepseek.com` |
| `FATFISH_TEMPERATURE` | 说话有多发散，0～2 | `0.7` |
| `TAVILY_API_KEY` | 联网搜索用的 key，不填就用默认后端 | `tvly-xxxx` |
| `UI_THEME` | 默认配色 | `dark` 或留空 |

> 改完**必须重启**才生效 —— 所以有了「保存并重启」这个按钮。

## 五、装插件（就是把一个文件夹拷进去）

插件 = 磁盘上的**一个文件夹**，里面有一份 `plugin.json`。

**装**：把插件文件夹整个拷进工作台目录下的 `plugins` 里，就成了 `plugins\插件名\plugin.json`。

**哪有现成的**：官方插件合集在 [FatFish-Plugins](https://github.com/Baimenlou-code/Fatfish-Plugins) —— 视觉理解、生图两插件都在里面，下载 zip 解压后把文件夹拷进 `plugins\` 就行。

**用**：点顶栏的 **「插件」** 按钮，从按钮下面弹出一个列表：

- 每个已装插件一行，**点一行就是启动 / 停止**；
- 行尾的 **⚙** 进设置页，可以启用 / 禁用（改完立刻生效，不用重启）；
- 列表最下面有「**＋ 添加插件**」的位置，就是提醒你把文件夹拷进 `plugins`；
- QQ 桥接也在这个列表里（命令：`/qq on`、`/qq off`、`/qq status`）。

## 六、出毛病了先看这几条

| 症状 | 原因 | 怎么办 |
|---|---|---|
| 灯是红的，说没找到 API Key | `.env` 没放对地方，或者被存成了 `.env.txt` | 放到程序旁边，文件名必须正好是 `.env` |
| 改了配置没反应 | 配置只在启动时读一次 | 用「保存并重启」，或手动关掉再开 |
| 它说「不允许访问这个路径」 | 你让它动工作台目录以外的东西 | 把工作台目录改到你想让它工作的位置，或把文件挪进来 |
| 一直弹审批窗，烦 | 审批档位太严 | 点顶栏的锁，换到「除敏感外免批」 |
| 窗口点了没反应 | 可能被拖到副屏，副屏拔掉了 | 下次启动会自动拉回主屏；程序记住了窗口大小，不会丢 |
| 余额那一格显示「—」 | 还没查过 | 点一下那一格，立刻刷新 |
| 报错了不知道原因 | — | 打开底部「日志」页，把**最后几行**贴出来，基本就能定位 |

## 七、彩蛋 🥚

- 这个界面的配色不是「调出来」的：是拿一个老牌工具（Cheat Engine）的截图**逐像素取样**再搬过来的 —— 所以底色、分隔线、工具栏的灰，都能对到具体色值。这也是它看着像个专业工具、而不像个玩具的原因。
- 状态栏那句「**工具 12 个**」是当场数出来的，不是写死的数字。你装一个插件，这个数会自己变大。
- 对话区没有气泡，只有左边一根 3 像素的色条 —— 因为这里经常整段贴代码和文档，气泡会把它挤得没法读。
